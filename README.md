# SOLO Aquatics practice schedule — Pool Relay embed preview

A replica of SOLO Aquatics' **Schedule** page with the typed "Fall 2024" practice table replaced by
two live [Pool Relay](https://www.poolrelay.com) calendars.

Not the official SOLO Aquatics website. The official page is
<https://www.gomotionapp.com/team/solo/page/practices/schedule>. The preview says so in a ribbon
across the top.

## What is on the page

| Calendar | Embed | Layout |
|---|---|---|
| Every group, day by day | `aTB6o4WtcGDaYWXfG2knOA` | one day, one column per practice group |
| Your swimmer's week | `of91jvhRnmTObuHuW2GrMX` | Mon–Sun week for one group, picked under **Teams** |

No practice time or date is typed into `index.html`. The season line under the heading comes from
`live.js` (`data-live="through"`), which reads the same published schedule as the calendars.

## Where the schedule came from

The team's own table (labeled Fall 2024, matching Burgess Pool's current grid), entered in Pool
Relay at Burgess Pool's Performance Pool for weekdays Sep 8 – Dec 23 and Saturdays. Lanes are an
estimate: the team's page names no lanes.
